给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**示例 1：**
```text
**输入：**[7,1,5,3,6,4]
**输出：**5
**解释：**在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```


## 动态规划

- 状态转移方程： $F(x) = Max(F(x-1),minPrice)$ 
- 时间复杂度： $O(n)$
- 空间复杂度： $O(n)$
```java
package com.taoes.code.dp;

import org.junit.Assert;

import java.util.Arrays;

public class L121 {
    public static void main(String[] args) {
        Solution s = new Solution();
        Assert.assertEquals(5, s.maxProfit(new int[]{7, 1, 5, 3, 6, 4}));
        Assert.assertEquals(4, s.maxProfit(new int[]{1, 2, 3, 4, 5}));
        Assert.assertEquals(0, s.maxProfit(new int[]{7,6,4,3,1}));
    }

    static class Solution {
        public int maxProfit(int[] prices) {
            int minPrice = prices[0];
            int[] maxResult = new int[prices.length];

            for (int i = 1; i < prices.length; i++) {
                if (prices[i] < minPrice) {
                    minPrice = prices[i];
                }
                maxResult[i] = Math.max(maxResult[i - 1], prices[i] - minPrice);
            }
            return maxResult[prices.length - 1];
        }
    }


}
```
