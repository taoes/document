罗马数字包含以下七种字符: I， V， X， L，C，D 和 M。

字符 数值 I 1 V 5 X 10 L 50 C 100 D 500 M 1000 例如， 罗马数字 2 写做 II ，即为两个并列的 1 。12 写做 XII ，即为 X + II 。 27 写做 XXVII, 即为 XX + V + II 。
通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 IIII，而是 IV。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4 。同样地，数字 9 表示为 IX。这个特殊的规则只适用于以下六种情况：

I 可以放在 V (5) 和 X (10) 的左边，来表示 4 和 9。 X 可以放在 L (50) 和 C (100) 的左边，来表示 40 和 90。 C 可以放在 D (500) 和 M (1000) 的左边，来表示 400 和 900。 给定一个罗马数字，将其转换成整数
## 整体替换法
```java
package com.taoes.code;

import org.junit.Assert;

import java.util.HashMap;
import java.util.Map;

public class L03 {
    public static void main(String[] args) {
        Solution solution = new Solution();
        Assert.assertEquals(3, solution.romanToInt2("III"));
        Assert.assertEquals(7, solution.romanToInt2("VII"));
        Assert.assertEquals(11, solution.romanToInt2("XI"));

        Assert.assertEquals(4, solution.romanToInt2("IV"));
        Assert.assertEquals(9, solution.romanToInt2("IX"));
        Assert.assertEquals(1994, solution.romanToInt2("MCMXCIV"));
    }

    static class Solution {
        static Map<Character, Integer> flagValue = new HashMap<>();
        static Map<String, String> doubleFlagValue = new HashMap<>();

        static {

            flagValue.put('I', 1);
            flagValue.put('V', 5);
            flagValue.put('X', 10);
            flagValue.put('L', 50);
            flagValue.put('C', 100);
            flagValue.put('D', 500);
            flagValue.put('M', 1000);

            // 4,9,40,90,400,900
            doubleFlagValue.put("IV", "IIII");
            doubleFlagValue.put("IX", "VIIII");
            doubleFlagValue.put("XL", "XXXX");
            doubleFlagValue.put("XC", "LXXXX");
            doubleFlagValue.put("CD", "CCCC");
            doubleFlagValue.put("CM", "DCCCC");

        }


        public int romanToInt2(String s) {
            for (String dkey : doubleFlagValue.keySet()) {
                s = s.replaceAll(dkey, doubleFlagValue.get(dkey));
            }
            int sum = 0;
            for (int i = 0; i < s.length(); i++) {
                sum = sum + flagValue.get(s.charAt(i));
            }
            return sum;
        }
    }
}
```

## 符号替换法

```java
package com.taoes.code;

import org.junit.Assert;

import java.util.HashMap;
import java.util.Map;

public class L03 {
    public static void main(String[] args) {
        Solution solution = new Solution();
        Assert.assertEquals(3, solution.romanToInt("III"));
        Assert.assertEquals(7, solution.romanToInt("VII"));
        Assert.assertEquals(11, solution.romanToInt("XI"));

        Assert.assertEquals(4, solution.romanToInt("IV"));
        Assert.assertEquals(9, solution.romanToInt("IX"));
        Assert.assertEquals(1994, solution.romanToInt("MCMXCIV"));
    }

    static class Solution {
        public int romanToInt(String s) {
            Map<Character, Integer> flagValue = new HashMap<>();
            flagValue.put('I', 1);
            flagValue.put('V', 5);
            flagValue.put('X', 10);
            flagValue.put('L', 50);
            flagValue.put('C', 100);
            flagValue.put('D', 500);
            flagValue.put('M', 1000);

            int sum = 0;
            char[] ches = s.toCharArray();
            for (int i = 0; i < ches.length - 1; i++) {
                char ch = ches[i];
                if (flagValue.get(ch) >= flagValue.get(ches[i + 1])) {
                    sum = sum + flagValue.get(ch);
                } else {
                    sum = sum - flagValue.get(ch);
                }

            }


            return sum + flagValue.get(ches[ches.length - 1]);
        }
    }
}
```
