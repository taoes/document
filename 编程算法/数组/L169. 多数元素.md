给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。


## 方法 1: 哈希表

```java
public class L169MajorityElement {  
    public static void main(String[] args) {  
        Solution s = new Solution();  
        Assert.assertEquals(3, s.majorityElement(new int[]{3, 2, 3}));  
        Assert.assertEquals(2, s.majorityElement(new int[]{2, 2, 1, 1, 1, 2, 2}));  
    }  
  
    static class Solution {  
        public int majorityElement(int[] nums) {  
            Map<Integer, Integer> data = new HashMap<>();  
            for (int num : nums) {  
                data.compute(num, (k, v) -> v == null ? 1 : v + 1);  
                int count =  data.get(num);  
                if (count>= 1.0 * nums.length / 2){  
                    return num;  
                }  
            }  
            return 0;  
        }  
    }  
}
```
