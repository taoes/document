编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：
- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为** 1，那么这个数就是快乐数。

如果 `n` 是 _快乐数_ 就返回 `true` ；不是，则返回 `false` 。

**示例 1：**
**输入：**n = 19
**输出：**true
**解释：**
12 + 92 = 82
82 + 22 = 68
62 + 82 = 100
12 + 02 + 02 = 1

**示例 2：**
**输入：**n = 2
**输出：**false

**提示：**
- `1 <= n <= 231 - 1`


## 哈希表法
- 时间复杂度：  $O(logn)$
- 空间复杂度： $O(logn)$
```java
package com.taoes.code;

import org.junit.Assert;

import java.util.HashSet;
import java.util.Set;

public class L202HappyNumber {
    public static void main(String[] args) {
        Solution s = new Solution();
        Assert.assertTrue(s.isHappy(19));
        Assert.assertFalse(s.isHappy(2));
        Assert.assertFalse(s.isHappy(1001));

    }


    static class Solution {
        public boolean isHappy(int n) {
            Set<Integer> container = new HashSet<>();
            int tmp = n;

            while (!container.contains(tmp)) {
                if (tmp == 1) {
                    return true;
                }
                container.add(tmp);
                tmp = this.calc(tmp);
            }
            return false;
        }

        public int calc(int n) {
            int result = 0;
            while (n != 0) {
                int v = n % 10;
                result = result + v * v;
                n = n / 10;
            }
            return result;
        }
    }

}

```

## 快慢指针

```java
package com.taoes.code;

import org.junit.Assert;

import java.util.HashSet;
import java.util.Set;

import lombok.var;

public class L202HappyNumber {
    public static void main(String[] args) {
        var s = new Solution2();
        Assert.assertTrue(s.isHappy(19));
        Assert.assertFalse(s.isHappy(2));
        Assert.assertFalse(s.isHappy(1001));

    }

    static class Solution2 {
        public boolean isHappy(int n) {
            int slow = n;
            int fast = calc(n);

            while (fast != 1) {
                if (slow == fast) {
                    return false;
                }
                slow = calc(slow);
                fast = calc(calc(fast));

            }
            return true;
        }

        public int calc(int n) {
            int result = 0;
            while (n != 0) {
                int v = n % 10;
                result = result + v * v;
                n = n / 10;
            }
            return result;
        }
    }
}
```
