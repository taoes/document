给你两棵二叉树的根节点 `p` 和 `q` ，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。



## 递归

```java
package com.taoes.code.tree;  
  
import org.junit.Assert;  
  
public class L100 {  
    public static void main(String[] args) {  
        Solution solution = new Solution();  
        Assert.assertTrue(solution.isSameTree(TreeNode.buildTree(new Integer[]{1, 2, 3}), TreeNode.buildTree(new Integer[]{1, 2, 3})));  
        Assert.assertFalse(solution.isSameTree(TreeNode.buildTree(new Integer[]{1, 2, 3}), TreeNode.buildTree(new Integer[]{1, 2, 4})));  
    }  
  
  
    static class Solution {  
        public boolean isSameTree(TreeNode p, TreeNode q) {  
            if (p == null && q == null) {  
                return true;  
            }  
            if (p == null || q == null) {  
                return false;  
            }  
  
            if (p.val != q.val) {  
                return false;  
            }  
  
            return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);  
        }  
    }  
  
  
}
```
