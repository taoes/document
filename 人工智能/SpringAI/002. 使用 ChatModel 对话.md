ChatModel 的构建很简单


```java
@Bean  
public DeepSeekApi deepSeekApi() {  
  return DeepSeekApi.builder().apiKey(System.getenv("DEEPSEEK_API_KEY")).build();  
}  
  
@Bean  
public ChatModel chatModel(DeepSeekApi deepSeekApi) {  
  return DeepSeekChatModel.builder().deepSeekApi(deepSeekApi).build();  
}
```

## 非流式对话

```java
@GetMapping(value = "/model/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)  
public ChatResponse chat(String message) {  
  if (message == null || message.trim().isEmpty()) {  
    return ChatResponse.of("empty message");  
  }  
  try {  
    Message systemMessage = new SystemMessage("你是一个数学方程解题的助手");  
    Message userMessage = new UserMessage("请问 3x+6 =9 ,x = ?");  
    var callResult = chatModel.call(systemMessage, userMessage);  
    return ChatResponse.of(callResult);  
  } catch (Exception e) {  
    return ChatResponse.of(e.getLocalizedMessage());  
  }  
}
```


## 2. 流式对话

```java
@GetMapping(value = "/model/chat/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)  
public Flux<ChatResponse> streamChat(String message) {  
  if (message == null || message.trim().isEmpty()) {  
    return Flux.just(ChatResponse.of("empty message"));  
  }  
  try {  
  
    Message systemMessage = new SystemMessage("你是一个数学方程解题的助手");  
    Message userMessage = new UserMessage("请问 3x+6 =9 ,x = ?");  
    return chatModel.stream(systemMessage, userMessage).map(ChatResponse::of);  
  } catch (Exception e) {  
    return Flux.just(ChatResponse.of(e.getLocalizedMessage()));  
  }  
}
```
