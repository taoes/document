实现$pow(x,n)$ 即计算 `x` 的整数 `n` 次幂函数（即，$X^n$ ）。


## 快速幂算法
- 时间复杂度: $O(log n)$
- 空间复杂度: $O(log n)$

```java
package com.taoes.code;

import org.junit.Assert;

public class L050Power {
    public static void main(String[] args) {
        Solution s = new Solution();
        Assert.assertEquals(1024.0, s.myPow(2.0, 10), 0.0001);
        Assert.assertEquals(2048.0, s.myPow(2.0, 11), 0.0001);
    }

    static class Solution {
        public double myPow(double x, int n) {

            if (n <= 1) {
                return n == 1 ? x : 1;
            }
            if (n % 2 == 0) {
                double v = myPow(x, n / 2);
                return v * v;
            } else {
                double v = myPow(x, n / 2);
                return v * v * x;
            }
        }
    }
}
```
